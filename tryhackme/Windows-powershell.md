# Windows PowerShell (TryHackMe)

Date: Oct 31, 2026

## What I learned

- **How PowerShell works:** I understand the logic behind how commands are built, so I don't need to memorize them.
- **Finding the commands I need:** I can look up commands and how to use them on my own (`Get-Command`, `Get-Help`, `-Examples`).
- **Objects and properties:** PowerShell is object-oriented. Commands return objects, and each object has properties I can work with.
- **Why it matters:** once you have practice, PowerShell is very efficient for doing tasks and automating them with reusable scripts.
